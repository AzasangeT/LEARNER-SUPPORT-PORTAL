# Student Support Portal 

## Project Overview 

The Student Support Porta is a web-based system designed to help learners manage their learning activities and communicate with assessors. 

The portal allows students to track their progress, view their tasks , request support, and upload documents. Assessors can monitor learner progress, manage support requests and view learner information. 

## Problem Statement

Learners currently use different douments and messages to record their tasks, support requests and progress. This can make it difficult for assessors to track learner progress and identify learners who need support. 

## Our Solution

We are developing a centralised Student Support Portal that brings all these activities together in one system. 

## Main Features 

## Learner 

- Login and Registration 
- Learner dashboard 
- View dashboard 
- Track learning progress
- Request Support 
- Track support progress
- Upload documents 
- View announcements 
- Access learning progress
- Play a mini-game 

## Assessor 

- Assessor dashboard 
- View learners 
- Monitor learner progress 
- View outstanding tasks 
- Manage support requests 
- Manage support bookings 
- View learner documents 
- View / make announcements
