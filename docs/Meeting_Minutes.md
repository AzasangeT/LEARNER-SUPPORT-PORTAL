Agenda
Discuss the current learner-support problem.
Discuss the proposed portal.
Identify system requirements.
Identify users and their responsibilities.
Discuss project features.
Discussion

The team discussed the difficulties learners and assessors experience when learner information is stored across different documents and messages.

The team agreed that a centralised Learner Support Portal would make it easier to manage tasks, support requests and learner progress.

The main users were identified as learners and assessors.

The team discussed the following features:

User registration and login
Learner dashboard
Task management
Support requests
Request-status tracking
Announcements
Document uploads
Progress tracking
Mini-coding game
Assessor management functions
Decisions Made
Develop a web-based Learner Support Portal.
Use Firebase for authentication and data storage.
Provide separate functionality for learners and assessors.
Include task and support-request management.
Include progress tracking.
