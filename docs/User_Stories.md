USER STORIES 

* Skills Track User Stories

Landing Page

* Learner

As a learner, I want to access the Skills Track landing page so that I can learn more about the school and the services available to me.

* Assessor

As an assessor, I want to access the Skills Track landing page so that I can learn more about the school and access the portal.


* Registration

* Learner

As a learner, I want to register for a Skills Track account so that I can access the learner portal and its available features.

* Assessor

As an assessor, I want to register for an assessor account so that I can access the assessor portal and perform my responsibilities.



* Login

* Learner

As a learner, I want to log into the portal using my registered account details so that I can securely access my learner dashboard.

* Assessor

As an assessor, I want to log into the portal using my registered account details so that I can securely access my assessor dashboard.



* Learner Dashboard

* Learner

As a learner, I want to access a central dashboard so that I can easily navigate to my tasks, progress, bookings, resources, and coding game.

* Assessor

As an assessor, I want to access a central dashboard so that I can easily navigate to learner information, support requests, tasks, progress, and resources.



* Dashboard Navigation

* Learner

As a learner, I want to use the side navigation bar to access different sections of the portal so that I can easily find and manage my work.

* Assessor

As an assessor, I want to use the side navigation bar to access different sections of the portal so that I can efficiently manage learner information and my assessor responsibilities.



* Tasks

* Learner

As a learner, I want to add and manage my tasks so that I can keep track of the work I need to complete.

* Assessor

As an assessor, I want to view learner tasks so that I can monitor outstanding work and track learner activity.



* Progress Tracking

* Learner

As a learner, I want to view my progress so that I can monitor my performance and identify work that still needs to be completed.

* Assessor

As an assessor, I want to view learner progress so that I can monitor performance and identify learners who may require additional support.


* Support Bookings

* Learner

As a learner, I want to make a support booking so that I can request assistance from an assessor when I need help.

* Assessor

As an assessor, I want to view and manage learner support bookings so that I can respond to learners who require assistance.



* Support Request Status

* Learner

As a learner, I want to view the status of my support request so that I know whether my request is pending, being handled, or completed.**

* Assessor

As an assessor, I want to update the status of learner support requests so that learners can see the progress of their requests.**



* Document Uploads

* Learner

As a learner, I want to upload documents to the portal so that I can keep my required work and supporting documents organised and accessible.**

* Assessor

As an assessor, I want to view learner documents where appropriate so that I can access documents submitted by learners when monitoring their work.**



* Learning Resources

* Learner

As a learner, I want to access and download learning resources so that I can use them to support my studies and complete my work.**

* Assessor

As an assessor, I want to upload learning resources and documents so that learners can access materials that support their learning.**



* Mini-Coding Game

Learner

As a learner, I want to access the mini-coding game from my dashboard so that I can practise my programming skills in an interactive way.**

* Assessor

As an assessor, I want to manage or monitor the coding game where applicable so that I can support the learner's programming development.**



* Progress Summary


As a learner, I want to view and print my progress summary so that I can keep a record of my learning progress.**

As an assessor, I want to review and approve a learner's progress summary so that the learner can access an accurate record of their progress.**
