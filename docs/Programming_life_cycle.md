
PROGRAMMING LIFE CYCLE PLAN 

| Phase                       | Activities                                                                                                                                                                                                               | Deliverables                                                         | Time          |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------- | ------------- |
| **1. Analysis**             | Identify the problem and purpose of the Student Portal. Identify the target users, gather requirements, and determine the main features such as login, dashboard, student information, and database functionality.       | Problem statement, user requirements, and list of system features.   | **Week 1**    |
| **2. Design**               | Design the user interface and system structure. Create layouts for the login page, dashboard, and other pages. Plan navigation, system flow, and the Firebase database structure. Create wireframes/prototypes in Figma. | Wireframes, UI designs, system flow, and database structure.         | **Week 2**    |
| **3. Coding**               | Develop the website using HTML and CSS. Use JavaScript to add functionality. Implement Firebase Authentication and Firestore/database functionality. Connect the frontend to Firebase and integrate team members' work.  | Working website, JavaScript functionality, and Firebase integration. | **Weeks 3–5** |
| **4. Testing**              | Test individual features and the complete system. Test login, forms, buttons, navigation, and database operations. Identify, document, and fix bugs and errors.                                                          | Test results, bug reports, and corrected system.                     | **Week 6**    |
| **5. Implementation**       | Combine all completed components and prepare the final working system. Run/deploy the application and ensure that users can access and use the system correctly.                                                         | Fully functional Student Portal.                                     | **Week 7**    |
| **6. Review & Improvement** | Evaluate the final system against the original requirements. Collect feedback from users and team members. Identify areas for improvement, fix remaining issues, and improve the user experience.                        | Final improved system and project evaluation.                        | **Week 8**    |
