As a user how do I login:

* Landing Page, Registration and Login Use Case
When a user opens the system, they are taken to the Skills Track landing page. From the landing page, the user can learn more about the school and the services provided.

If the user does not have an account, they can navigate to the Registration page. The registration page requires the user to enter their personal and account details. The user can then register as either a Learner or an Assessor.

Once the registration process is completed successfully, the user is redirected to the Login page. The user can enter their registered email address and password to log into the system.

After a successful login, the system identifies the user's role and provides access to the appropriate Learner or Assessor dashboard.

* Learner Dashboard Use Stories 

Once the learner successfully logs into the portal, they are redirected to the Learner Dashboard. From the dashboard, the learner can access the main features available to them, including Tasks, Progress Tracking, Bookings, Resources, and the Coding Game.

The learner can navigate between these sections using the dashboard navigation. Each section provides access to information and resources specific to the learner. This allows the learner to manage their tasks, monitor their progress, make support bookings, access learning resources, and use the coding game from one central location.


*Learner Dashboard and Navigation

When a learner logs into the portal, they are taken to the Learner Dashboard. The dashboard provides the learner with easy access to the different features available to them, including adding and managing tasks, tracking their progress, making support bookings, downloading learner resources, and accessing the coding game.

The dashboard includes a side navigation bar that allows the learner to move between the different sections of the portal. The learner can select the specific page they want to access from the navigation bar, and the system will take them to the corresponding page.

This allows the learner to easily access and manage their work without having to search through multiple pages. The dashboard acts as a central location where the learner can access their tasks, progress information, bookings, resources, and other features available to their account.


* Assessor Dashboard and Support Management

An assessor wants to review all support requests and bookings submitted by learners so that they can provide assistance and respond to learners who require support.

When an assessor logs into the portal, they are taken to the Assessor Dashboard. The dashboard has a similar layout and navigation structure to the Learner Dashboard, making it easy for the assessor to navigate through the system. However, the features available to the assessor are specific to their role and responsibilities.

From the Assessor Dashboard, the assessor can view and manage learner support bookings, track learner progress, review the tasks created by learners, and upload learning resources and documents for learners to access.

The assessor can use the side navigation bar to move between these sections. This provides the assessor with a central location to monitor learner activity, respond to support requests, review outstanding work, and provide resources to assist learners.


* Additional Learner and Assessor Use Cases

* Learner Uploads Documents

A learner wants to upload documents to the portal so that they can keep their required work and supporting documents in one place.

After logging into the portal, the learner can navigate to the Document Upload section from the Learner Dashboard. The learner can select a document from their device and upload it to their account. The uploaded document is then stored and can be accessed through the portal.


* Assessor Updates Support Request Status

An assessor wants to update the status of a learner's support request so that the learner can see the progress of their request.

The assessor can navigate to the Support Requests/Bookings section of the Assessor Dashboard. The assessor can select a specific request and update its status based on the current progress of the request. The updated status is then available for the learner to view.

The assessor has permission to edit relevant request information because of their role within the system.

* Learner Accesses the Mini-Coding Game

A learner wants to log into the portal and access the mini-coding game to practise their programming skills.

The learner logs into the portal and is redirected to the **Learner Dashboard**. From the side navigation bar, the learner can select the Coding Game option. The system then takes the learner to the game page, where they can access and play the game.

* Learner Prints Their Progress Summary

A learner wants to print their progress summary so that they can have a physical or downloadable record of their progress.

The learner can access their Progress Summary from the Learner Dashboard. If the progress summary requires assessor approval before it can be printed, the learner must first submit the request for approval. The assessor can review the learner's progress summary and approve it. Once approved, the learner can access and print their progress summary.
