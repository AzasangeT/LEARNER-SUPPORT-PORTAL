1. Client Brief
Learner Support Portal
Client

SkillsTrack Training Centre

Project Overview

SkillsTrack Training Centre requires a centralised system to help learners manage their learning activities and support requests.

The proposed Learner Support Portal will allow learners to log in, manage tasks, view announcements, request support, track progress and access learning activities.

Assessors will be able to view learner information, manage support requests and update request statuses.

Main Objectives
Centralise learner information.
Improve communication between learners and assessors.
Help learners manage their tasks and progress.
Make support requests easier to submit and track.
Give assessors better visibility of learner progress.
Main Users
Learners
Assessors
